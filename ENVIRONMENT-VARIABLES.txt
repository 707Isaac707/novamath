NOVA MATH v1.3.2 - VERCEL ENVIRONMENT VARIABLES

REQUIRED FOR ACCOUNTS
MEDIAHUB_AUTH_SECRET
- Required for username/password accounts and signed sessions.
- Keep the same value after accounts are created.

MEDIAHUB_ADMIN_USERNAME
- Set this to the exact Nova Math account username that should have admin access.
- This is a Nova Math username, not your Vercel or Discord username.
- Matching is case-insensitive. Redeploy after changing it.

REQUIRED STORAGE
UPSTASH_REDIS_REST_URL
UPSTASH_REDIS_REST_TOKEN
- Nova also accepts KV_REST_API_URL + KV_REST_API_TOKEN instead.
- Use one credential pair, not both.

NOVA AI / UNOROUTER
UNOROUTER_API_KEY
- Required for Nova AI. Keep the key private.

UNOROUTER_MODEL
- Optional primary model. Recommended current free primary: space-bunny-alpha:free

UNOROUTER_FALLBACK_MODELS
- Optional comma-separated fallback model IDs.
- If omitted, Nova uses built-in free fallbacks.

OPTIONAL MEDIA / ART
YOUTUBE_API_KEY
STEAMGRIDDB_API_KEY

DISCORD
FOOD_REQUEST_DISCORD_WEBHOOK
- Snack Drop notifications.

NOVA_REPORTS_WEBHOOK
- Private user issue and broken-item reports.
- Recommended target: your private #request-log or reports channel.

NOVA_ADMIN_ALERTS_WEBHOOK
- Private admin alerts and webhook test messages.
- If NOVA_REPORTS_WEBHOOK is not set, issue reports fall back to this webhook.

PROXY / BROWSER
- No JELLYFIN_BRIDGE_URL, SCRAMJET_BROWSER_URL, or WISP_URL variables are required.
- The existing browser/proxy uses its built-in defaults.

OPTIONAL BOTASAURUS SPORTS DISCOVERY
BOTASAURUS_API_URL
- Base URL of the separately hosted Botasaurus Docker service.
- Example format: https://your-botasaurus-service.example
- The existing /api/sports-api function calls /sports/channels on this service.
- Leaving it unset keeps the existing IPTV-org + IPTV Cat behavior.

VERCEL HOBBY
- Nova Math v1.3.2 keeps the same 11 /api functions. No new serverless function was added.
