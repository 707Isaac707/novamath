NOVA MATH v1.3.2 - VERCEL HOBBY EDITION

This archive is a complete Nova Math project.
index.html is at the ZIP root and Vercel Functions are in /api.

USE YOUR EXISTING PROJECT
- Vercel project: novamath
- Current production domain: totallynovamath.duckdns.org
- Do not create a new Nova Math project unless you intentionally want a separate deployment.

DEPLOY
1. Open the existing novamath project in Vercel.
2. Deploy/upload this complete project as the next production version using your normal Vercel workflow.
3. Confirm the deployment is Production.
4. Existing domains attached to novamath will follow the new production deployment automatically.

ENVIRONMENT
See ENVIRONMENT-VARIABLES.txt.
Important v1.3.2 additions:
- NOVA_REPORTS_WEBHOOK
- NOVA_ADMIN_ALERTS_WEBHOOK

MEDIAHUB_ADMIN_USERNAME must match the username of the Nova Math account you want to use as admin.

AFTER ENVIRONMENT VARIABLE CHANGES
Redeploy once so the new production deployment receives the variables.

HOBBY PLAN
- This build keeps 11 deployable /api functions, below the 12-function limit.
- No new function was added for reports or admin alerts. They use the existing platform API.
- The browser/proxy keeps its existing built-in backend defaults.
